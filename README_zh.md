# lft-rice-et：基于公众天气预报的 7 天参考作物蒸散量与水稻需水量预报

本仓库提供基于公众天气预报的 7 天参考作物蒸散量与水稻需水量预报的代码和训练好的模型。

输入是农户日常能看到的城市公众天气预报（中国天气网格式）：最高气温、最低气温、天气现象文字、风力文字。输出是当天及之后 6 天的参考作物蒸散量 ETₒ（FAO-56/ASCE 短参考面），以及标准条件下的水稻需水量 ETc = Kc × ETₒ。预报时不需要任何站点观测资料。

## 模型

- **点预报**：两类模型各训练 3 个种子，等权平均作为业务方案。
  - 滞后融合 Transformer（LFT）：输入当期预报，加上前 6 天对同一日期发布的各期预报。
  - GRU：只输入当期预报。
- **预报区间**：分位数 LFT，给出 5%–95% 分位数。
- **训练数据**：全国 583 个气象站，2015 年 3 月至 2018 年 12 月；2019 年用于早停。模型在独立检验年 2020 年评估之前已冻结。

## 精度

2020 年，582 站，样本外：

| 指标 | 数值 |
|---|---|
| ETₒ RMSE（7 天合计） | 0.744 mm/d |
| ETₒ RMSE（当天 → 第 7 天） | 0.676 → 0.829 mm/d |
| NSE | 0.81 |
| 90% 区间实际覆盖率 | 89.5% |
| 稻区标准条件 ETc RMSE | 1.08 mm/d |
| 7 天累计 ETc 误差 | 16% |

详见 [MODEL_CARD.md](MODEL_CARD.md)。

## 安装与使用

```bash
pip install -r requirements.txt
python -m unittest discover -s tests
python -m lft_et.cli --input examples/example_messages.json --output forecast.csv
```

**输入（JSON）**
- `station`：站号；若是新站点，改为给出经纬度、海拔和气候区代码。
- `issue_date`：发布日期。
- `messages`：发布日当天的报文，以及前 6 天的报文（可选）。
- 每条报文的天气、最高温、最低温、风力，都是以 "1"–"15" 为键的字典；"1" 表示发布当天。

`examples/example_messages.json` 是一个合成示例，不是真实存档报文。

**输出列**
- `eto`：集成预报；`eto_lft`、`eto_gru`：两类模型各自的预报。
- `eto_q05`…`eto_q95`：分位数。
- 若用 `--kc kc.csv` 提供 Kc 文件（列：station, month, Kc, rice_season_month），另输出 `kc`、`rice_season` 和 `etc` = Kc × ETₒ。

单位均为 mm/d。

**新站点**：填经纬度和海拔；气候区取 `data/stations.csv` 中最近站点的代码：CC、SC、NC、NEC、NWC、IM、QTP。

## 文件说明

| 路径 | 内容 |
|---|---|
| `lft_et/features.py` | 把公众预报报文解析成模型输入，与原始训练流程逐项一致 |
| `lft_et/models.py` | LFT、GRU 网络和输入编码器 |
| `lft_et/predict.py`、`cli.py` | 集成预报、ETc 换算、命令行 |
| `model/` | 编码器（JSON）、权重（LFT 和 GRU 各 3 个种子，分位数 LFT 1 个）、配置、导出检验结果 |
| `data/stations.csv` | 站点坐标、气候区、稻作区、是否稻作站 |
| `VERIFICATION.json` | 端到端核验结果（见下文） |

**核验方法**：用本包从原始报文重建输入，再做预报，与原始训练流程的预测逐条比较。共 30 站、10,574 条序列，输入完全一致，预报最大差值 2×10⁻⁶ mm/d。

2018–2020 年的样本外回算预报可向作者索取。

## 说明

- ETₒ 是计算得到的参考值，ETc 是充分供水稻田的需水量，二者都不是灌水量。灌水量还取决于降雨、田面水层和渗漏。
- 预报精度随预见期增加而下降。
- 西南和西北稻区若没有本地站参与训练，迁移效果较差。本发布的全国模型训练时已包含这两个区。
- 本包不附带公众预报原始报文。
